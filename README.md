# Organy-Project
مشروع تحليل بيانات شركة العرجاني للنقل والشحن باستخدام Power BI. الهدف تحويل بيانات التشغيل (رحلات، سائقين، عملاء، مصروفات) إلى لوحة تحكم تفاعلية تدعم اتخاذ قرارات أسرع. يتضمن 4 صفحات: نظرة عامة، تحليل السائقين، العملاء الأكثر ربحية، والمسارات لتقييم الكفاءة. تجربة قوية حولت الأرقام المتناثرة إلى قصة واضحة عبر Dashboard متكامل.
